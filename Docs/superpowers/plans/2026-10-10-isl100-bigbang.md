# ISL 100-Word Big-Bang Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand SignBridge AI from 50 to 100 dynamic ISL words with sign photos for all 100 and a single retrained Softmax(100) model released as SBAI-MDL-ISL-2.0.0.

**Architecture:** Big-bang Approach B — freeze 100-word vocab, curate only the 50 new glosses, extract 100 display photos from dataset frames, rebuild FV-2.0/SPLIT-2.0 tensors at (45,189), retrain LSTM (+GRU challenger) to Softmax(100), then migrate DB/backend/frontend together with rollback to 1.0.0 retained.

**Tech Stack:** Python 3.11, TF/Keras (LSTM/GRU), MediaPipe/OpenCV, FastAPI + SQLAlchemy/Alembic + PostgreSQL, React+TS + Tailwind, pytest/Jest/Playwright.

**Spec:** `plan.md`, `Docs/00_MVP_SCOPE_ADDENDUM.md`, `data/dataset/annotations/class_map.csv` (50 rows ISL_001-050), `data/assets/manifest.csv` (50 empty URIs), `frontend/src/views/Vocab.tsx`, `frontend/src/views/TextToSign.tsx`, `backend/app/routers/speech.py`, `ai/models/lstm.py` (NCLASS=50)

## Global Constraints

- SEQ_LEN=45, FEAT_DIM=189 exactly; dim mismatch returns 422 `expected 189 got N`.
- Model ID format `SBAI-MDL-ISL-X.Y.Z`; new artifact is `SBAI-MDL-ISL-2.0.0`.
- Class IDs `ISL_001…ISL_100`, label UNIQUE, all `sign_type=Dynamic` unless cut-rule forces otherwise.
- Cut rule: any class with <15 clips across >=10 pooled signers moves to v1.1 queue.
- Signer split 70/15/15 by signer with zero cross-split overlap; frozen test checksums recorded.
- Gates: accuracy >=90%, macro-F1 >=0.90, inference p95 <200ms, sustained >=15 FPS, coverage >=80%, 0 Criticals.
- Auth: open `GET /health|/model|/classes`, JWT/OAuth on the rest.
- Retention 90/180/30/30; blobs in object storage / `data/assets`, never RDBMS bytes.
- ISL500 frames are research-only — prefer INCLUDE CC-BY-4.0 frames for public UI display.

## Review Focus

- New gloss with <15 clips across <10 signers silently passing curation — expect it to be cut to v1.1 with a record, not trained.
- Dataset frame shown in UI without license clearance — expect INCLUDE-first selection with source logged per photo.
- Blurry/occluded keyframe chosen as sign photo — expect sharpness + 2-hand validation reject with logged reason.
- `GET /classes` returning 50 after migration — expect exactly 100 rows from DB seed.
- `text-to-sign` phrase "good morning" split into two signs — expect longest-phrase-first match to keep it one ISL_008 item.
- Softmax(50) weights loaded against 100-class head — expect fail-fast version mismatch, never silent truncation.
